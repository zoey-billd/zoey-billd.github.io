# Container Habitat Generator

## 项目概览

这个项目是一个 Houdini 模块化箱体空间生成器。它不是随机摆放箱子，而是用规则和参数自动生成有层级、有平台、有楼梯、有支撑、可继续迭代的箱体居住空间。

当前版本定位是结构化 blockout / MVP：先保证大形、空间逻辑和可复现布局，再继续扩展材质、道具和 UE 场景落地。

## 一句话流程

```text
视觉目标与比例 -> 箱体布局规则 -> 模块类型 -> 平台/楼梯/支撑 -> 属性写入 -> HDA 封装 -> 参数验证
```

## 设计目标

- 在 Hero Camera 下形成清晰的高低层次、前后关系和视觉中心。
- 用确定性随机控制布局，保证同一个 seed 可以复现并继续调试。
- 支持多层箱体、错位、悬挑、平台连接、栏杆、梯子、楼梯和支撑结构。
- 给几何体写入模块、组件、楼层、路线和材质属性，为后续筛选、调试和 UE 替换预留数据。

## 主要规则与参数

- `levels`：控制生成楼层数量。
- `rows`：控制横向排列数量。
- `depth_columns`：控制前后深度。
- `seed`：控制可复现的随机结果。
- `offset_strength`：控制箱体错位程度。
- `cantilever_strength`：控制悬挑程度。
- `platform_coverage`：控制平台覆盖范围。
- `style`：控制整体风格倾向。

这些参数共同决定场景是否读得懂：箱体是否过于平、是否有支撑、平台之间是否有交通关系、顶部轮廓是否足够轻。

## 模块拆分

每个箱体不是一个简单 cube，而是由组件拼装出来：

- 墙体、角柱、波纹加强筋；
- 门板、门锁、把手、通风口、玻璃框；
- 平台、栏杆、立柱、斜撑；
- 梯子、楼梯和少量场景道具。

当前支持 `closed`、`open`、`drawer`、`glass` 等基本箱体类型。这样后续可以单独替换某类组件，也可以按组件类型单独赋材质、隐藏、导出或调试。

## 技术流程

1. 根据楼层、行列和深度参数生成箱体候选位置。
2. 使用 seed、错位强度和悬挑强度生成可复现的空间变化。
3. 为不同箱体分配模块类型，并在局部坐标系中生成门窗、波纹板和细节组件。
4. 根据箱体层级和相邻关系生成平台、栏杆、支撑、梯子与楼梯。
5. 写入 `module`、`component`、`module_id`、`level`、`route_id`、`supported` 和材质相关属性。
6. 封装为 HDA 后通过参数变化验证布局是否仍然稳定。

## 属性与交付价值

程序化资产不仅要生成形状，还要生成数据。这个项目把模块和结构信息写到几何体上，让后续可以：

- 只显示某一层的平台或栏杆；
- 检查哪些悬挑箱体缺少支撑；
- 快速替换玻璃、金属、箱体墙面等材质；
- 在 UE 中根据属性继续做材质或实例替换；
- 为后续路径连通性检查和交互区域划分预留接口。

## 当前状态与后续计划

当前版本已经能展示模块化箱体空间的结构骨架，适合作为技术美术作品集中“从参考图到规则化 blockout”的案例。下一步可以继续补：

- 参数变化对照图；
- 支撑/悬挑 debug 视图；
- 更完整的空间连通性检查；
- UE 中的材质替换与场景落地；
- 道具、灯光和最终镜头包装。
